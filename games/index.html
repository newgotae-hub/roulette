Games와 기존 툴을 같은 흐름으로

Snake, Number Merge, Brick Breaker를 모두 바로 열 수 있는 카드로 두고, 아래 줄에는 기존 랜덤리픽 툴도 함께 두어 허브가 따로 놀지 않게 맞췄습니다.

Playable

Snake

짧은 아케이드 루프와 빠른 재시작이 강점인 첫 게임입니다. 게임 탭에 가장 먼저 들어가도 부담이 없습니다.

바로 플레이 Playable

Number Merge

짧은 세션으로 반복하기 좋은 숫자 퍼즐입니다. Snake 다음에 이어지는 두 번째 플레이 타이틀입니다.

열기 Playable

Brick Breaker

벽돌을 깨며 짧게 반복하기 좋은 세 번째 게임입니다. 같은 허브 톤 안에서 아케이드 손맛을 더해 줍니다.

바로 플레이 Tool

룰렛

사람, 주제, 순서처럼 하나를 바로 골라야 할 때 가장 빠르게 이어지는 기본 도구입니다.

열기 Tool

럭키 드로우

번호나 당첨 결과를 간단하게 보여 주고 기록까지 남기기 좋은 추첨 도구입니다.

열기 Tool

팀 나누기

수업, 워크숍, 모임에서 균형 있게 팀을 나누고 결과를 바로 공유하기 좋습니다.

왜 이런 구성으로 두었나
Games 탭이 혼자 다른 서비스처럼 보이면 기존 랜덤리픽 흐름이 끊깁니다. 그래서 허브도 같은 내비게이션, 같은 정보 밀도, 같은 신뢰 링크 구조를 유지하면서 플레이 가능한 게임만 앞줄에 모이도록 정리했습니다.
