현재 바로 열 수 있는 전체 게임 목록

아래 카드는 모두 실제 게임 라우트로 연결됩니다. 허브는 flashy한 쇼케이스보다, 들어가고 나오는 흐름이 빠른 Randomly Pick식 대시보드에 가깝게 유지했습니다.

Arcade

Snake

가장 빠르게 시작할 수 있는 클래식 아케이드 게임입니다. 모드 전환과 보너스 루프가 있어 반복 플레이에 강합니다.

플레이 Puzzle

Number Merge

짧은 세션에서도 흐름이 끊기지 않는 머지 퍼즐입니다. 숫자를 쌓아 가며 점수를 만드는 타입입니다.

열기 Arcade

Brick Breaker

반사 신경과 손맛 중심의 벽돌 깨기 게임입니다. 모바일에서도 바로 잡히는 조작감을 목표로 만든 타이틀입니다.

플레이 Memory

Memory Match

카드를 뒤집어 짝을 맞추는 기억력 게임입니다. 짧고 반복적인 흐름이라 브라우저에서 부담 없이 하기 좋습니다.

열기 Logic

Minesweeper Lite

작은 보드와 첫 클릭 안전 규칙으로 가볍게 시작하는 지뢰찾기입니다. 짧은 집중 세션에 맞춘 버전입니다.

열기 Reflex

Reaction Tap

짧은 대기와 한 번의 탭으로 반응 속도를 확인하는 게임입니다. Daily 챌린지와 기록 흐름이 있습니다.

열기 Puzzle

Color Lines

구슬을 옮겨 줄을 만드는 보드 퍼즐입니다. 다음 공 배치를 보며 계획적으로 정리하는 타입입니다.

열기 Puzzle

Bubble Pop

같은 색 클러스터를 골라 터뜨리는 퍼즐입니다. 큰 묶음을 만들수록 점수 흐름이 좋아집니다.

열기 Memory

Sequence Flash

순서를 보고 그대로 따라 하는 기억 게임입니다. 짧은 라운드 구조라 여러 번 도전하기 쉽습니다.

열기 Puzzle

Sliding Puzzle

15-퍼즐 스타일로 타일을 밀어 원래 순서를 복구하는 게임입니다. 느리지만 몰입감 있는 클래식 퍼즐입니다.

왜 이런 구성으로 묶었나
게임 수가 늘어날수록 허브가 별도 사이트처럼 보이면 기존 Randomly Pick 톤이 깨집니다. 그래서 같은 내비게이션, 같은 신뢰 링크, 같은 정보 밀도를 유지한 채 실제 플레이 가능한 카드만 깔끔하게 모아 두었습니다.
