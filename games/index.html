게임 탭은 이제 실제로 플레이할 수 있는 게임으로 시작합니다. 먼저 Snake를 즐기고, 다음에는 Number Merge로 이어지는 라인업을 같은 허브에서 확인하세요.

Snake 플레이 라인업 보기
실플레이 게임 라인업 중심 모바일 최적화 추가 게임 확장 가능

Snake는 허브의 첫 번째 실플레이 게임입니다.

누구나 아는 아케이드 루프에 명확한 조작, 보이는 점수, 짧은 재시작 흐름을 더해 두었습니다. 짧은 휴식용으로도 좋고, 게임 탭이 실제 콘텐츠로 이어진다는 점을 보여 주기에도 적합합니다.

  • 방향키, WASD, 모바일 스와이프를 모두 지원합니다.
  • 현재 점수와 최고 점수를 한눈에 볼 수 있습니다.
  • 같은 허브에서 다음 게임으로 바로 이어질 수 있습니다.

목표 점수 10 한 번의 탭으로 재시작

성장하는 게임 라인업

Snake가 먼저 있고, 그다음에는 Number Merge가 이어집니다. 이 허브는 새로운 게임이 붙을수록 더 보기 쉬운 목록형 대시보드가 되도록 설계했습니다.

1번 타이틀

Snake

허브의 첫 번째 실플레이 게임입니다. 클래식 아케이드 감각과 깔끔한 재시작 흐름을 갖췄습니다.

플레이하기 다음 게임

Number Merge

번호를 합쳐 가는 가벼운 퍼즐 게임입니다. 짧게 즐기기 좋고, 허브의 두 번째 실게임으로 자연스럽게 이어집니다.

곧 보기 빠른 선택

룰렛

사람, 주제, 순서처럼 바로 하나를 골라야 할 때 가장 빠르게 쓸 수 있습니다.

열기 추첨

럭키 드로우

결과를 간단하고, 눈에 잘 보이고, 공유하기 쉽게 만들고 싶을 때 좋습니다.

열기 배정

사다리

순서 배정, 대진, 행사 배정을 할 때 흐름 자체를 보여 주기에 좋습니다.

열기 팀 나누기

팀 나누기

수업, 업무, 모임에서 균형 잡힌 팀을 만들고 싶을 때 바로 이어서 쓸 수 있습니다.

열기 결정

동전 던지기

예/아니오처럼 아주 빠른 결정을 내려야 할 때 가장 간단하게 쓸 수 있습니다.

열기 주사위

주사위

라운드 진행, 테이블 게임, 간단한 확률 확인처럼 굴림이 필요한 순간에 잘 맞습니다.

게임 탭은 이제 실제 플레이가 가능한 게임을 먼저 보여 주고, 다음 게임이 자연스럽게 이어지는 라인업형 목록을 갖춥니다. 페이지 자체의 쓰임새를 살리면서도 앞으로 새 타이틀을 추가하기 쉬운 구조입니다.
