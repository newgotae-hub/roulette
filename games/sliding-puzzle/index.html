Mode note

Classic은 자유 풀이, Timed는 시간 압박, Daily는 오늘의 같은 보드입니다.

When it fits

짧게 시작해도 되고, 조금 오래 붙잡아도 되는 퍼즐입니다.

짧은 집중 리셋

한두 번만 움직여도 보드가 바로 달라져서, 짧은 휴식 동안 머리를 다시 켜기 좋습니다.

반복 플레이

Timed와 Daily 모드는 같은 보드를 더 빠르게 푸는 재미가 있어서, 다시 열 이유가 분명합니다.

When another game is better

이 퍼즐이 모든 상황의 정답은 아닙니다.

순간 반응이 필요할 때

손이 먼저 움직여야 하는 기분이면 Reaction Tap이 더 잘 맞습니다.

한 번에 끝내고 싶을 때

아예 더 짧은 세션을 원한다면 Number Merge나 Snake의 짧은 라운드가 더 편할 수 있습니다.
