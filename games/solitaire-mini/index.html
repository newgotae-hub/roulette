어떻게 쓰나요

한 판의 흐름을 짧게 이해하고 바로 다시 시작할 수 있게 만든 카드 퍼즐입니다.

모드

Classic은 자유 연습용, Timed는 1분 도전용, Daily는 오늘의 같은 보드를 반복해서 푸는 모드입니다.

반복 플레이

Draw, Auto move, Undo가 모두 빠르게 이어져서 짧게 한 판씩 다시 도전하기 좋습니다.

이 게임이 맞는 때

잠깐 머리 식히고 싶을 때, 손에 익은 솔리테어를 브라우저에서 바로 하고 싶을 때, 혹은 일일 보드로 같은 조건을 다시 풀어보고 싶을 때 잘 맞습니다.

플레이 방법

카드 이동 규칙은 단순하게 유지하고, 읽기 쉬운 상태를 먼저 만드는 데 집중했습니다.

1. 카드를 한 장 뽑습니다. Stock 버튼을 누르면 Waste에 카드가 쌓입니다.
2. 같은 무늬를 foundation에 쌓습니다. A부터 K까지 순서대로 정리합니다.
3. tableau를 열어 길을 만듭니다. 막힌 칸을 풀고, 다음 이동이 보이도록 배치를 바꿉니다.

이럴 때 좋습니다

Speed보다 정리감이 중요한 짧은 세션에 잘 맞습니다.

짧은 쉬는 시간 타이머 없이 한 판만 해도 되고, 중간에 멈췄다가 다시 이어가기 쉽습니다.
일일 도전 daily는 같은 seed로 다시 풀 수 있어서, 오늘의 한 판을 비교하기 좋습니다.
모바일/웹뷰 탭과 버튼이 크고, 한 손 조작에도 맞게 보드가 밀집되어 있습니다.
