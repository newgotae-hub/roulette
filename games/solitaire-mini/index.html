읽기 쉬운 보드와 빠른 다시하기에 맞춘 작은 솔리테어입니다.

모드

일반은 자유 연습, 시간제한은 1분 도전, 데일리는 오늘의 같은 보드를 반복하는 모드입니다.

반복 플레이

카드 뽑기, 자동 정리, 되돌리기가 항상 보여서 바로 다시 도전하기 쉽습니다.

이럴 때 맞습니다

잠깐 쉬고 싶을 때, 손에 익은 카드 게임을 브라우저에서 바로 하고 싶을 때 잘 맞습니다.

플레이 방법

룰은 단순하게, 상태는 읽기 쉽게 유지했습니다.

1. 카드 뽑기. Stock을 누르면 Waste에 카드가 쌓입니다.
2. 기초 더미에 정리합니다. 같은 무늬를 A부터 K까지 순서대로 올립니다.
3. 전개열을 열어 길을 만듭니다. 막힌 칸을 풀어서 다음 이동이 보이게 만듭니다.

이럴 때 좋습니다

속도보다 정리감이 중요한 짧은 세션에 잘 맞습니다.

짧은 쉬는 시간 한 판만 하고 끝내도 되고, 중간에 멈췄다가 다시 이어가기 쉽습니다.
데일리 도전 같은 seed로 다시 풀 수 있어서 오늘 보드를 비교하기 좋습니다.
모바일과 웹뷰 버튼과 카드가 커서 작은 화면에서도 읽기 쉽습니다.
