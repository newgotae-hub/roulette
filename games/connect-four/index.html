Connect Four

같은 기기에서 번갈아 두는 Connect Four입니다. 열 버튼을 누르면 디스크가 아래로 떨어지고, 먼저 네 개를 이어 놓는 쪽이 이깁니다. 혼자 빠르게 한 판 하고 싶다면 CPU 모드도 쓸 수 있습니다.

열 버튼을 누르면 첫 수가 떨어집니다. 같은 기기에서 바로 번갈아 둘 수 있습니다.
모바일에서는 열 버튼을 탭하세요. 키보드는 1-7, ← →, Enter, Space, R를 지원합니다.

짧은 안내

Connect Four는 규칙이 단순해서 빠르게 시작할 수 있지만, 한 번 두기 시작하면 읽어야 할 수가 많아집니다. Randomly Pick 안에서 가볍게 한 판 하고 빠져나가기 좋은 방식으로 정리했습니다.

How to Play

1. 모드를 고릅니다. 같은 기기에서 두 명이 번갈아 두거나, 혼자 CPU와 대전할 수 있습니다.
2. 열을 누릅니다. 디스크는 선택한 열의 가장 아래 빈 칸으로 떨어집니다.
3. 네 개를 잇습니다. 가로, 세로, 대각선 어느 방향이든 네 개가 이어지면 이깁니다.

When to Use It

짧은 대결 커피 한 잔 시간 동안 바로 한 판 끝내기 좋습니다.
가족/친구용 같은 기기에서 번갈아 두기 쉬워서 설명 없이 바로 즐길 수 있습니다.
모바일 웹뷰 세로 화면에서도 열 버튼만 누르면 되는 구조라 편합니다.

When Another Game Is Better

혼자 느긋한 퍼즐

차례를 읽는 대신 혼자 몰입하고 싶다면 Number Merge가 더 잘 맞습니다.

더 빠른 리듬

손이 먼저 움직이는 느낌을 원하면 Snake나 Brick Breaker가 더 가볍습니다.
