Sequence Flash

빛나는 패드 순서를 보고 그대로 따라 누르는 Simon 스타일 메모리 게임입니다. 라운드가 길어질수록 리듬이 짧아지고, 데일리 챌린지로 오늘의 같은 시퀀스를 다시 도전할 수도 있습니다.

자유 · 준비됨
시작을 누르면 패드가 순서대로 빛납니다. 보여준 순서 그대로 누르면 다음 라운드가 시작됩니다.
모바일에서는 먼저 빛나는 순서를 보고, 그다음 같은 패드를 차례대로 탭하세요. 패드가 클수록 첫 플레이가 훨씬 덜 헷갈립니다.

어떻게 돌아가나요

Sequence Flash는 반응 속도보다 기억 유지가 중요합니다. 라운드가 하나 늘 때마다 시퀀스가 한 칸 더 길어지고, 같은 패턴을 놓치지 않고 이어서 기억하는지가 핵심이 됩니다.

첫 플레이 흐름

시작을 누르면 먼저 보기가 시작되고, 그다음 입력 구간으로 넘어갑니다. 그래서 규칙 설명 없이도 “먼저 보고, 나중에 누른다”는 흐름이 자연스럽게 전달됩니다.

데일리 챌린지

데일리 챌린지는 오늘 모두가 같은 시드로 시작합니다. 계정 없이도 “오늘은 어디까지 갔는지” 비교하기 좋게 만든 반복 루프입니다.

랜덤리픽에 맞는 이유

화려한 네온 사이트처럼 보이기보다, 사이트 안에서 바로 이해되는 게임 탭처럼 보이게 구성했습니다. 규칙, 상태, 다음 행동이 한 화면에 자연스럽게 붙어 있습니다.

플레이 방법

보는 구간과 누르는 구간이 분리되어 있어서, 기억 유지에만 집중하면 됩니다.

1. 먼저 봅니다. 시작하면 패드가 순서대로 빛나고, 그동안은 입력하지 않습니다.
2. 그대로 누릅니다. 방금 본 순서를 같은 차례로 누르면 다음 라운드가 이어집니다.
3. 점점 빨라집니다. 라운드가 길어질수록 플래시가 짧아져서 기억과 리듬을 같이 챙겨야 합니다.

이럴 때 잘 맞습니다

짧게 시작하고, 실수하면 바로 다시 할 수 있는 가벼운 메모리 게임이 필요할 때 좋습니다.

짧은 집중 휴식 한 판이 짧아서 화면을 오래 붙잡지 않아도 됩니다.
데일리 재도전 오늘의 같은 시퀀스를 다시 해 보는 루프가 자연스럽습니다.
터치 중심 데모 큰 패드를 탭하는 구조라 모바일과 앱 웹뷰에서 설명이 쉽습니다.
