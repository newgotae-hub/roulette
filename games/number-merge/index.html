Number Merge

같은 숫자를 밀어서 합치고, 더 큰 타일을 만들면서 보드를 비워 두는 2048 스타일 퍼즐입니다. 소리 없이 차분하게 한 판씩 이어 가기 좋은 게임입니다.

퍼즐 시작 게임 허브
키보드 + 스와이프 한 수 되돌리기 오늘의 도전판 최고 점수 로컬 저장 목표 타일 2048
준비됨
방향키, WASD, 또는 보드 스와이프로 모든 타일을 한 번에 움직일 수 있습니다.

아무 방향으로 한 번 밀면 시작됩니다. 같은 숫자는 더 큰 타일 하나로 합쳐집니다. 오늘의 도전은 모두 같은 시작판을 씁니다.

어떻게 돌아가나요

Number Merge는 보드가 한 번에 움직이고, 같은 숫자는 한 번만 합쳐지는 단순한 규칙으로 되어 있습니다. 덕분에 모바일과 데스크톱 모두에서 금방 이해할 수 있습니다.

빠른 조작

방향키, WASD, 스와이프, 화면 버튼이 모두 같은 동작을 합니다. U는 되돌리기, N은 같은 시작판으로 다시 시작합니다.

오늘의 도전

오늘의 도전 버튼을 누르면 같은 보드에서 다시 시작합니다. 매일 같은 조건으로 점수를 올려 보기 좋습니다.

이 페이지가 좋은 이유

보드만 던져 두지 않고 점수, 최고 기록, 오늘의 기록, 되돌리기, 터치 조작, 설명 문단까지 같이 둬서 사이트 안의 정식 게임 탭처럼 읽히게 만들었습니다.

플레이 방법

한 수를 둘 때마다 공간을 만들고, 다음 합치기를 준비하고, 큰 숫자를 한쪽에 모아 두는 것이 핵심입니다.

1. 보드를 민다. 한 번 움직이면 같은 방향으로 모든 타일이 같이 이동합니다.
2. 같은 숫자를 합친다. 값이 같은 두 타일은 한 번의 이동에서 더 큰 숫자 하나로 합쳐집니다.
3. 빈 칸을 유지한다. 더 이상 움직일 수 없으면 라운드가 끝나므로, 항상 다음 수를 남겨 두는 게 중요합니다.

이럴 때 잘 맞습니다

반응 속도보다 생각하는 퍼즐을 원할 때, 그리고 짧게 시작해서 다시 한 판 하고 싶을 때 잘 맞습니다.

조용한 퍼즐 휴식 타이머 압박 없이 한두 수씩 생각하고 다시 시작하기 좋습니다.
점수 경쟁 최고 점수와 오늘 최고가 바로 보여서 짧은 기록 경쟁이 쉽습니다.
터치 + 키보드 데모 데스크톱과 모바일 입력이 모두 자연스러운 구조라 게임 셸 검수에도 잘 맞습니다.
