Política de privacidad

Fecha de entrada en vigor: 6 de marzo de 2026

Randomly Pick ofrece herramientas aleatorias en el navegador, como ruleta, sorteo, escalera, cara o cruz y dados. Esta página explica qué información puede procesarse cuando usas el sitio.

1. ¿Qué información puede procesarse?

  • Pueden recopilarse datos básicos de acceso como hora de visita, tipo de navegador, información del dispositivo y dirección IP.
  • Si nos contactas, pueden procesarse tu nombre, correo electrónico y el contenido del mensaje.
  • Las entradas de las herramientas, como listas de participantes y resultados, normalmente se gestionan dentro de tu navegador.

2. ¿Por qué usamos esta información?

  • Para operar el sitio de forma estable y corregir errores.
  • Para detectar abusos, proteger la seguridad y mantener la disponibilidad.
  • Para responder a consultas de soporte, publicidad y colaboración.
  • Para entender el tráfico y el rendimiento publicitario y así mejorar el servicio.

3. Procesamiento local en el navegador

Las funciones principales de sorteo están diseñadas para ejecutarse en tu navegador. Algunas funciones de conveniencia pueden usar almacenamiento del navegador, como localStorage, pero las listas y el estado del sorteo no se guardan en nuestros servidores salvo que una integración de terceros lo requiera expresamente.

4. Cookies y servicios de terceros

El sitio puede usar cookies, localStorage o tecnologías similares para funciones básicas, analítica y publicidad. También podemos usar servicios de terceros como Google AdSense, Google Analytics, Google Tag Manager, Microsoft Clarity y Userback, que pueden procesar datos según sus propias políticas. Para visitantes del EEE, Reino Unido y Suiza, puede solicitarse consentimiento mediante un banner o una CMP antes de mostrar anuncios personalizados. Si no hay consentimiento, la publicidad puede mostrarse de forma limitada o no personalizada.

5. Conservación y derechos del usuario

Conservamos la información solo durante el tiempo necesario por motivos operativos o legales. Cuando la legislación aplicable lo permita, puedes solicitar acceso, corrección o eliminación de tus datos personales.

6. Contacto

Para consultas relacionadas con la privacidad, escríbenos a newgotae@gmail.com.
