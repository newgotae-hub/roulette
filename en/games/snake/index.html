How it works

이번 버전은 시작과 재시작 Speed, 모바일 Controls, 보너스 흐름을 더 빠르게 읽히도록 다듬었습니다.

Controls

Keyboard, WASD, swipe, board tap, and arrow buttons are all supported.

Replay loop

실패 후 버튼이나 방향 입력으로 바로 새 판을 열 수 있어서 Short sessions 반복에 잘 맞습니다.

How to play

Start quickly, miss quickly, and jump right back in.

1. Pick a direction. 사과를 먹으면서 몸 Length를 늘립니다.
2. Avoid walls and your own tail. Each mode changes the pacing a bit.
3. Chase bonus apples. 연속 플레이가 이어질수록 Score 효율이 좋아집니다.

When it fits

Snake works best when you want fast reactions and a clean rhythm loop.

Short focus breaks Each run is short and easy to restart.
