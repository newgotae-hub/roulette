How it works

Sudoku Mini keeps the familiar Sudoku logic but trims the board down to 4x4. That makes it a better fit for a static browser game tab: short rounds, readable status, and touch-friendly input without turning into a thin number widget.

Why 4x4 works here

It is quick to teach, fast to restart, and much easier to keep polished on both mobile and desktop than a full 9x9 board.

Shared daily puzzle

The daily challenge uses a stable seed so everyone gets the same board for the day. That adds replay value without accounts or backend state.

How to play

Fill every blank with the correct digit while keeping rows, columns, and 2x2 boxes clean.

1. Select an empty cell. Only blank cells can be changed.
2. Enter a digit. Tap one of the keypad buttons from 1 to 4.
3. Clear the board. When every value is correct, the puzzle clears instantly.
