How it works

Word Swipe is deliberately not an open-ended dictionary tool. It is a contained puzzle: each board has a realistic small target list, clear progress, and a finish state. That keeps the page useful as a game instead of a thin letter gimmick.

Fast first play

The first board opens with short, readable words like PLAY and GAME. The HUD keeps the target word, solved count, and current path visible so the rules teach themselves.

Shared daily puzzle

The daily challenge uses a date seed, so everyone gets the same board for the day. That adds replay value without accounts, ranking servers, or long setup.

Once the runtime connects, the current target word, remaining target list, and board progress can update inside this card without changing the layout.

How to play

Build connected paths, clear the approved words, and finish the board in a few clean moves.

1. Start on the first letter. Press or tap the opening cell of the word you want to trace.
2. Stay connected. You can move horizontally, vertically, or diagonally, but each letter can only be used once in the same path.
3. Match the exact target. When your path matches a remaining target word, the solve lands immediately and the board updates.
