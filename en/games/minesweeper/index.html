How it works

Minesweeper Lite is a small board game that rewards quick reading instead of long setup. Open the first square, follow the number clues, and expand the safe area one move at a time.

Core rules

Reveal opens a square. Flag marks a square you want to come back to later. The number on each open square tells you how many mines touch it. Zero expands the board fast.

Why it is lite

This version keeps the board small, the restart flow quick, and the touch targets comfortable so it works well in short sessions and embedded browsers.

How to Play

Read the numbers, keep the board open, and use Flag only where you are not sure yet.

1. Start with Reveal The first square is always safe, so you can open the board with confidence.
2. Use Flag for guesses Mark uncertain squares, then come back after you read the nearby numbers.
3. Look for zeros Empty squares expand the board quickly and make the next move easier.

When to Use It

It is a good fit when you want a short break that still keeps your brain active.

Quick break A fast one-minute focus game between tasks.
Pattern reading A simple way to practice number and adjacency reading.
Daily challenge Same seed, same board, better reason to come back tomorrow.
