How it works

Number Merge keeps the board readable and the rules simple: every move slides all tiles, equal numbers merge once per move, and the round ends when no move is left.

Quick controls

Arrow keys, WASD, swipe, and on-screen buttons all do the same move. Use U to undo and N to replay the current board.

Daily challenge

Use the daily challenge button when you want the same puzzle seed everyone else gets today. It makes replay and score chasing feel more like a small event.

What makes it good

This page is not just a board. It keeps score, saves your best run locally, adds a daily challenge loop, supports keyboard and touch, and explains the puzzle in the same practical style as the rest of Randomly Pick.

How to play

Each move should either create space, build the next merge, or protect one corner for the big numbers.

1. Slide the whole board. Every swipe or keypress shifts every tile in one direction.
2. Match equal numbers. Two tiles with the same value merge into a single bigger tile.
3. Keep a lane open. When the grid fills up, the round ends if there is no valid move left.

When this game fits

Use Number Merge when you want a slower puzzle loop than Snake, but still want something you can understand in seconds.
