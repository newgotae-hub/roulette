How it works

Color Lines is about route planning, not speed. Each move is deliberate: open a path, connect five matching colors, and avoid letting the preview pieces trap the center of the board.

First-play flow

The first tap selects a ball. The second tap only works if there is an open route through empty cells, so the board teaches pathfinding without a long tutorial.

Daily board

Use the daily board when you want the same seed everyone else gets today. That makes this puzzle feel replayable even without a leaderboard.

How to play

Each turn is about using the current open lanes before the preview row makes the board tighter.

1. Select a ball. Tap any filled cell to lock in the color you want to move.
2. Follow an open path. Only empty-cell routes count, so blocked moves force you to reorganize the board first.
3. Make a line of five. Horizontal, vertical, and diagonal lines all clear and open space again.

When this game fits

Color Lines works best when you want something thoughtful, tidy, and easy to continue for one more run.

Calm puzzle breaks There is no timer, so you can think through a route without rushing.
Daily repeat visits The shared daily board gives the game a small return loop without adding account systems.
Touch-first strategy Tap-based movement works naturally on phones and app webviews, while desktop remains clear and precise.
