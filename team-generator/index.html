팀 나누기 (랜덤/균형)

이름만 입력하면 랜덤으로 팀을 생성하고, 점수를 함께 입력하면 균형있는 팀을 생성합니다. 엑셀파일에서 그대로 복사붙여넣으세요!

2~12팀 지원점수 미입력은 평균 반영예상 팀 크기 바로 확인

입력 포맷

이름 / 점수

엑셀파일 그대로 복사

생성 방식

랜덤 / 균형

상황별로 즉시 전환

출력 결과

복사 / CSV

회의용 공유까지 바로

입력 설정

엑셀 / 탭 / 슬래시 지원

배정 방식

명단을 붙여넣으면 예상 팀 크기가 바로 계산됩니다.

    팀 생성 전 상태입니다

    왼쪽에 명단을 붙여넣고 팀 수를 정한 뒤 생성 버튼을 누르세요. 점수 칸이 있으면 밸런스 모드에서 총점 차이를 줄이도록 자동 조정합니다.

    사용 방법

    • Excel에서 이름/점수 두 열을 그대로 복사해 입력창에 붙여넣습니다.
    • 이름만 있는 목록이면 완전 랜덤, 점수까지 있으면 점수 밸런스를 선택합니다.
    • 원하는 팀 수를 정하면 예상 팀 크기를 바로 보여줍니다.
    • 팀별 평균 점수와 총점을 함께 보면서 결과를 검토합니다.
    • 결과는 복사 버튼이나 CSV 저장으로 바로 회의 자료에 붙일 수 있습니다.

    FAQ

    점수 밸런스 모드는 완벽하게 동일한 총점을 보장하나요?

    아닙니다. 팀 정원 제약과 실제 점수 분포를 같이 고려해 편차를 줄이는 방식입니다.

    점수를 일부만 넣어도 되나요?

    됩니다. 점수 없는 항목은 입력된 점수 평균으로 계산하고 경고 메시지로 알려줍니다.

    엑셀에서 붙여넣으면 자동으로 줄이 나뉘나요?

    네. Excel 두 열 복사 시 들어오는 탭 구분을 그대로 인식합니다. 이름/점수, 이름,점수 형식도 지원합니다.

    팀 수가 인원수보다 많으면 어떻게 되나요?

    현재 인원수에 맞는 최대 팀 수로 자동 조정합니다.
