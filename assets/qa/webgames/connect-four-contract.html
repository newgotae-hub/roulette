Connect Four QA Contract Harness

This fallback page exists so the QA runner can exercise the Connect Four hook contract before the live route ships. It keeps the game loop deterministic, mobile-friendly, and easy to inspect from screenshots.

Hooks exposed: QA_READY, render_game_to_text(), advanceTime(ms), reset(). Use the column buttons or keyboard arrows plus Enter/Space to drop a disc.
