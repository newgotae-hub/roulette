How it works

Designed for short sessions, clear state, and repeat runs.

Replay loop
Draw, auto move, and undo all produce visible state changes so browser QA can confirm the harness without touching product code.
Mode note
Daily mode uses a deterministic date seed. Timed mode has a short countdown so the runner can verify `advanceTime(ms)` and timeout state.
Hooks exposed: QA_READY, render_game_to_text(), advanceTime(ms), reset().
